# DC OPF 带高惩罚削负荷 (opf_load_shedding_case30)

基于目录内标准 MATPOWER/IEEE 表格 `opf_load_shedding_case30.xlsx` 建模。表格中的 `Bus`、`Gen`、`Branch`、`Gencost` 是系统基础参数来源。 本算例为多时段 DC OPF，不含启停；削负荷用于保证极端时段可行，但惩罚足够高。

per-unit load 曲线如下：

```text
[0.50, 0.46, 0.44, 0.43, 0.47, 0.58, 0.75, 0.92, 1.05, 1.13, 1.18, 1.12, 1.03, 0.96, 0.93, 0.98, 1.10, 1.22, 1.28, 1.18, 1.03, 0.86, 0.68, 0.55]
```

`SheddingPenalty = 10000`。

## 决策变量

- 机组出力 `p[i,t]`。
- 母线削负荷 `shed[b,t]`。
- 母线相角 `theta[b,t]` 和线路潮流 `flow[l,t]`。

## 约束条件

1. 可用机组满足 `GenPMin <= p <= GenPMax`，不可用机组出力为 0。
2. `0 <= shed[b,t] <= BusPD[b] * LoadShape[t]`。
3. 节点平衡中削负荷作为减少需求处理。
4. DC 潮流、线路容量、参考母线约束按标准建模。
5. 机组爬坡上/下限为 `0.35 * GenPMax`。

## 目标函数

最小化线性燃料成本和削负荷惩罚。局部线路瓶颈版本。
