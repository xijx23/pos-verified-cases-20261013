# ED-03: case30 二次经济调度与网络约束

基于目录内标准 MATPOWER/IEEE 表格 `ed_quadratic_case30.xlsx` 建立 24 时段安全约束经济调度问题。所有可用机组视为在线，不建模启停；系统容量和线路容量已按原始可解原则设置。

per-unit load 曲线如下，按 `Bus.PD` 分配：

```text
[0.62, 0.58, 0.55, 0.54, 0.57, 0.65, 0.78, 0.90, 0.98, 1.03, 1.05, 1.01, 0.97, 0.94, 0.93, 0.95, 1.00, 1.07, 1.12, 1.08, 1.00, 0.91, 0.80, 0.69]
```

## 决策变量

- 机组出力 `p[i,t]`。
- 母线相角 `theta[b,t]`。
- 线路潮流 `flow[l,t]`。

## 约束条件

1. `GenStatus = 1` 的机组满足 `GenPMin[i] <= p[i,t] <= GenPMax[i]`，`GenStatus = 0` 的机组出力为 0。
2. 相邻时段爬坡上/下限均取 `0.30 * GenPMax[i]`。
3. 每个母线、每个时段满足 DC 节点功率平衡。
4. 线路潮流由相角差和 `BranchReactance` 决定，并满足 `BranchRateA`。
5. `BusType == 3` 的母线为参考母线，相角固定为 0。

## 目标函数

最小化 24 时段二次燃料成本：

`sum_t sum_i (Gencost.COST_3[i] * p[i,t]^2 + Gencost.COST_2[i] * p[i,t] + Gencost.COST_1[i])`。

该算例要求保留二次目标，不需要启停变量。
