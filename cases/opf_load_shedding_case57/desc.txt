# OPF-08: case57 带高惩罚削负荷的多时段 DC OPF

基于目录内标准 MATPOWER/IEEE 表格 `opf_load_shedding_case57.xlsx` 建立 24 时段 DC OPF。该算例没有机组启停，所有可用机组在线；削负荷变量只用于保证极端时段可行，惩罚足够高，正常情况下应优先发电供电。

per-unit load 曲线如下：

```text
[0.64, 0.59, 0.56, 0.55, 0.58, 0.66, 0.79, 0.92, 1.02, 1.08, 1.12, 1.08, 1.03, 0.99, 0.98, 1.00, 1.06, 1.14, 1.20, 1.15, 1.06, 0.95, 0.82, 0.70]
```

## 决策变量

- 机组出力 `p[i,t]`。
- 母线削负荷 `shed[b,t]`。
- 母线相角 `theta[b,t]` 和线路潮流 `flow[l,t]`。

## 约束条件

1. 可用机组满足 `GenPMin <= p <= GenPMax`，不可用机组出力为 0。
2. 母线削负荷满足 `0 <= shed[b,t] <= load[b,t]`。
3. 节点平衡中削负荷作为减少需求处理：发电注入减未供负荷后的需求等于网络净流出。
4. DC 潮流、线路容量、参考母线约束按标准建模。
5. 相邻时段机组爬坡上/下限均为 `0.35 * GenPMax`。

## 目标函数

最小化线性燃料成本和削负荷惩罚。削负荷惩罚为 10000 cost/MWh。
